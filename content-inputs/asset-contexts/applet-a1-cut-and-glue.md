# Applet A1: Cut and Glue Practice

## Type
Interactive HTML5 applet

## File Path
/fractions-module-content/applets/A1. M2-Fraction Cut and Glue Practice/index.html

## Duration
4 minutes

## What Student Does
1. Sees a piece of paper on screen
2. Uses virtual scissors to cut the paper
3. Must cut into EQUAL parts (halves, quarters)
4. Uses virtual glue to arrange pieces
5. Gets feedback on whether cuts are equal

## Interaction Type
- Drag and click
- Cutting tool
- Arranging pieces

## Concepts Taught
- Hands-on practice making equal parts
- Understanding that fractions require equal-sized pieces
- Visual feedback when pieces aren't equal

## Learning Goal
Student experiences firsthand that fraction pieces must be the same size.

## What Student Should Remember
When making fractions, all pieces MUST be equal — same size!

## Key Vocabulary Reinforced
- Equal parts
- Same size
- Cut
- Halves
- Quarters
