# Slide 4: Numerator and Denominator

## Type
Narration slide (no question)

## Duration
1 minute

## What's Shown
- The fraction 1/4 displayed large
- Arrow pointing to 1 labeled "Numerator"
- Arrow pointing to 4 labeled "Denominator"
- Visual breakdown of what each number means

## Purpose
Visual reference — clear labeling of fraction parts.

## Key Message
"In one-fourth, the numerator is 1 — it shows how many parts we have. The denominator is 4 — it shows total equal parts!"

## Concepts Reinforced
- Numerator = how many parts you have (top)
- Denominator = total parts (bottom)
- Visual memory aid for vocabulary

## Visual Elements
- Large 1/4 fraction
- Arrows with labels
- Color coding (numerator one color, denominator another)
